# Hair and Glow Salon - website concept

A static website concept for Hair and Glow Salon, Station Road, Ghatkopar East, Mumbai. It is an independent preview, not the salon's official website, and is set to noindex.

Business details come from the salon's public Google Maps listing. Services are limited to those named in public reviews. The WhatsApp button stays inactive until the salon's WhatsApp number is confirmed (see `WA_NUMBER` in `script.js`).
